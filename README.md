# BookSmart

Une application web pour la gestion de bibliothèque, permettant aux adhérents de gérer leurs emprunts et aux administrateurs de gérer le stock et les adhérents.

## Objectifs :
- Gérer le stock de livres.
- Automatiser la réservation en ligne.
- Suivre et gérer les emprunts et retours.
- Mettre en place un système de recommandation basé sur l'IA.

## Technologies :
- **Frontend :** HTML, CSS (Tailwind/Bootstrap), JavaScript, Chart.js
- **Backend :** FastAPI, SQLAlchemy, Pydantic
- **Base de données :** PostgreSQL
- **Machine Learning :** Cosine Similarity
- **Web Scraping :** Selenium
